# PRODUCT_SPEC.md

## 1. 產品名稱

LINE Hair Salon Ordering System

## 2. 產品目的

讓美髮沙龍設計師可直接在 LINE 群組內開啟圖形化叫貨介面，不必手動輸入：

```text
A02 10 已付款 小明
```

系統仍維持現有 LINE Bot、Google Sheet 與統計流程。

## 3. 目標使用者

### 設計師

可：

- 開啟 LIFF
- 搜尋商品
- 選擇多個商品
- 設定數量
- 選擇付款狀態
- 輸入客戶名稱
- 一次送出全部資料

### 管理者

V1 維持既有 Bot 與 Google Sheet 管理流程，不新增 LIFF 管理後台。

## 4. 使用流程

```text
群組輸入「叫貨」或點開 LIFF
  ↓
載入商品
  ↓
搜尋或瀏覽商品
  ↓
選商品
  ↓
輸入數量、付款、客戶
  ↓
加入購物車
  ↓
可繼續加入其他商品
  ↓
確認購物車
  ↓
送出全部
  ↓
LINE 群組收到固定格式訊息
  ↓
既有 Bot 解析並寫入 Google Sheet
```

## 5. 功能需求

### FR-001 商品載入

系統必須從 Google Apps Script API 讀取既有 Google Sheet 商品資料。

### FR-002 商品排序

商品必須依商品代號自然排序。

### FR-003 商品搜尋

可搜尋：

- 商品代號
- 商品名稱

### FR-004 商品分類

系統預留分類功能。

若 Google Sheet 沒有分類欄位，商品應歸入「全部商品」或「其他」。

### FR-005 多商品購物車

一次可加入多筆商品資料。

### FR-006 唯一鍵

購物車唯一鍵：

```text
商品代號 + 客戶名稱
```

### FR-007 覆蓋

相同商品、相同客戶再次加入時，覆蓋：

- 數量
- 付款方式

不可累加。

### FR-008 不同客戶

商品相同但客戶不同時，必須新增不同資料。

### FR-009 付款方式

固定支援：

- 已付款
- 未付款
- 自領

### FR-010 數量

數量必須：

- 為正整數
- 最小值為 1
- 最大值為 99
- 可使用加減按鈕
- 可直接輸入

### FR-011 客戶名稱

客戶名稱為必填，且不得包含半形或全形數字。

### FR-012 LINE 送出

送出時，每筆一行：

```text
商品代號 數量 付款方式 客戶名稱
```

### FR-013 多筆送出

多筆資料以換行分隔，維持單一文字訊息格式。

### FR-014 防重複送出

送出期間必須停用按鈕。

### FR-015 完成後關閉

成功送出後，可由 LIFF 關閉頁面。

### FR-016 總叫貨

設計師可從叫貨頁面切換至「總叫貨」，唯讀查看目前全部設計師的叫貨明細、筆數與商品總數，並可手動重新整理。

## 6. 非功能需求

- Mobile First
- 支援 LINE 內建瀏覽器
- 支援深色模式
- 30～100 項商品仍可快速搜尋
- 無外部 UI Framework
- 不在前端存放私密金鑰
- 保持既有 Bot 相容

## 7. V1 排除項目

- 備註
- 價格
- 折扣
- 商品圖片
- 庫存扣帳
- 管理者後台
- 多店管理

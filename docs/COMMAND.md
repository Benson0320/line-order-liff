# COMMAND.md

## 1. 既有 Bot 指令

本專案必須保留既有指令相容性。

已知指令：

```text
初始化
確認初始化
統計開始
統計結束
重新開放
叫貨
幫助
商品
```

實際指令仍以既有 LINE Bot 專案為準。

## 2. 叫貨指令

建議群組輸入：

```text
叫貨
```

Bot 回傳包含 LIFF URL 的按鈕或 Flex Message。

## 3. LIFF 送出的文字

LIFF 不新增特殊命令前綴，直接送出既有格式：

```text
A02 10 已付款 小明
```

多筆資料：

```text
A02 10 已付款 小明
A08 2 自領 小華
```

## 4. 不可變更

不得自行改為：

```text
商品：A02
數量：10
付款：已付款
客戶：小明
```

因為這會破壞既有 Bot 解析相容性。

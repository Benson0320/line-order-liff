# UI_SPEC.md

## 1. 設計原則

- Mobile First
- LINE 內建瀏覽器優先
- 操作區塊清楚
- 按鈕容易觸控
- 商品 30～100 項仍好操作
- 支援深色模式

## 2. 頁面結構

```text
Header
Status
Search
Category Tabs
Product List
Order Form
Cart
Preview
Submit Button
Toast / Dialog
```

## 3. Header

顯示：

```text
📦 設計師叫貨
```

可顯示目前使用者名稱，但不作為必填功能。

## 4. 搜尋

Placeholder：

```text
搜尋商品代號或名稱
```

搜尋規則：

- 不區分英文大小寫
- 可搜尋部分文字
- 同時搜尋商品代號與名稱

## 5. 分類

V1 預留：

- 全部
- 其他

未來 Google Sheet 有分類後再動態產生。

## 6. 商品列表

每筆顯示：

```text
A02
護髮精
單位：瓶
```

商品依代號排序。

## 7. 加入表單

選擇商品後顯示：

- 商品代號與名稱
- 數量
- 付款方式
- 客戶名稱
- 加入／更新購物車

付款方式：

```text
已付款
未付款
自領
```

## 8. 購物車

每筆顯示：

- 商品代號
- 商品名稱
- 數量
- 付款方式
- 客戶名稱
- 刪除按鈕

提供：

- 單筆刪除
- 全部清空

## 9. 覆蓋提示

同商品同客戶再次加入時，按鈕文字可顯示：

```text
更新購物車
```

完成後提示：

```text
已更新 A02／小明
```

## 10. 預覽

送出前顯示實際 LINE 文字：

```text
A02 10 已付款 小明
A08 2 自領 小華
```

## 11. 送出

按鈕：

```text
送出全部
```

規則：

- 購物車為空時停用
- 送出中停用
- 防止重複點擊
- 成功後顯示成功訊息
- 成功後關閉 LIFF

## 12. 錯誤狀態

必須顯示清楚錯誤：

- LIFF 初始化失敗
- 商品載入失敗
- 非 LINE 內開啟
- 客戶名稱未填
- 數量不正確
- 送出失敗

# DATABASE.md

## 1. 資料來源

目前主要資料來源為既有 Google Sheet。

本文件只定義 LIFF 前端需要的最低商品欄位，不強迫修改既有工作表。

## 2. 商品資料模型

建議欄位：

| 欄位 | 說明 | 必填 |
|---|---|---:|
| 商品代號 | 例如 A01 | 是 |
| 商品名稱 | 例如 洗髮精 | 是 |
| 單位 | 例如 瓶、盒 | 否 |
| 分類 | 例如 洗髮、護髮 | 否 |

## 3. 欄位相容策略

Apps Script API 應支援既有欄位名稱差異，例如：

商品代號可能為：

- 商品代號
- 代號
- 編號
- code

商品名稱可能為：

- 商品名稱
- 品名
- name

單位可能為：

- 單位
- unit

分類可能為：

- 分類
- category

## 4. 缺少分類欄位

若目前沒有分類欄位：

```text
category = "其他"
```

前端仍可正常顯示全部商品。

## 5. 訂單資料

LIFF V1 不直接定義新的訂單工作表。

訂單仍透過現有 LINE Bot 文字解析流程寫入既有資料。

## 6. 唯一鍵

前端購物車唯一鍵：

```text
normalize(product.code) + "::" + normalize(customerName)
```

客戶名稱僅去除前後空白，V1 不改變字形與大小寫規則。

## 7. 相容性要求

- 不刪除既有工作表。
- 不重新命名既有工作表。
- 不重新排列既有欄位。
- 新增分類欄時必須為可選欄位。
